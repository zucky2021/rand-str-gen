# 共通

## 概要

- 共通のコーディングルールを記述

## ルール

- インデントはスペース2つ
- ボーイスカウトの原則に従いコードは見つけたときよりも綺麗にする
- YAGNI (You Aren't Gonna Need It)の原則に従う
- Don't Repeat Yourselfの原則に従う
- KISS (Keep It Simple, Stupid)の原則に従う
- [MDN Style Guide](https://developer.mozilla.org/ja/docs/MDN/Writing_guidelines/Code_style_guide)に準拠していること
